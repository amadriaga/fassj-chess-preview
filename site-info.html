Website info

How this website works

What this site is built with, how it keeps you safe, and what it does with your information. This is Build 85, published November 21, 2026.

The basics

The FASSJ Chess Club website is a set of plain web pages, hosted by GitHub Pages. There is no database, no user accounts and no server program behind it, which leaves very little that can be attacked or go wrong. Every change is saved with a new build number, shown at the bottom of every page, so we always know which version you are looking at.

Security

CloudflareThe site is reached through Cloudflare, which protects it from attacks and floods of fake traffic.
Encrypted connection (HTTPS)Every page is sent over an encrypted connection; plain, unencrypted access is switched to HTTPS automatically. Older, weaker encryption (below TLS 1.2) is not accepted.
Content Security PolicyYour browser is told the page may only load its own files, and may only send forms to the two services named below (Google and Formspree). Anything else is blocked, even if someone tried to sneak it in.
No framingOther websites can’t show our pages inside theirs (a common trick to fool visitors).
No camera, microphone or locationThe site never asks for them, and the browser is told to refuse if anything tried.
Spam protectionEach form has a hidden spam trap that catches automated junk.

These protections apply on chess.fassj.org.

Your privacy

No trackingNo cookies, no analytics, no advertising trackers, and no outside scripts or fonts.
Sign-ups and advertising enquiriesSaved in a Google Sheet that only club officers can open. No email copies are sent.
Contact messagesDelivered to the club by Formspree, a form service.
Payments and donationsMade on Zeffy (FASSJ’s payment platform) or with Zelle from your own bank. Card and bank details never pass through this website.

Full details: Privacy & Disclaimer.

Software and tools

Web pagesHand-written HTML, CSS and JavaScript, with no frameworks or add-ons.
HostingGitHub Pages; domain and protection by Cloudflare.
FormsGoogle Sheets with Google Apps Script (sign-ups, advertising); Formspree (contact).
PaymentsZeffy and Zelle (FASSJ’s accounts).
QR codes and printablesQR codes made with segno; printable PDFs (flyers, program, forms) made with the Chromium browser.
BuildingBuilt by club volunteers with the help of Claude Code, an AI coding assistant. All files are kept in version control with an off-site backup.

See a problem?

If something looks wrong or broken, please let us know and mention the build number at the bottom of the page.
